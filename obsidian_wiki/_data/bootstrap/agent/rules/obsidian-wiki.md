# Obsidian Wiki Repository Rules

Resolve the nearest ancestor `.obsidian-wiki/config.toml`, then read repository
`AGENTS.md`. Use `.skills/llm-wiki/SKILL.md` for source authority and every
transaction. Task-specific files in `.skills/` refine that protocol without
creating direct-write paths. Invalid or missing configuration stops wiki work.
